eisy Backup

Configuration, Google Drive, USB, and NAS backup guide

Quick Start — Google Drive Backups

If you only want automatic backups to Google Drive, you do not need to open or configure the HTML web editor. Google Drive authentication and routine backup settings are managed through PG3x and IoX.

  1. Install eisy Backup from the PG3x Store.
  2. Open the plugin's Overview page, click Authenticate, and authorize access to your Google account.
  3. Open the plugin's Configuration page, enable Allow API Access, and click Save.
  4. Restart the plugin.
  5. Open the IoX Admin Console, select the eisy Backup controller, and enable Google Drive Backup.
  6. Configure your backup schedule and the number of backups to retain using the available IoX settings.
  7. Run a test backup and confirm that the archive appears in Google Drive.

No Google Cloud developer account, OAuth client ID, client secret, or HTML editor setup is required.

The plugin uses Google's drive.file permission. Your Google password is entered only on Google's authorization page.

If IoX still shows the old node profile

In the IoX Admin Console, right-click the eisy Backup node server and select Upload Profile (or the equivalent profile-upload command). Restart the Admin Console afterward if necessary.

Optional — HTML Configuration and Backup Management

The HTML editor is not required for Google Drive-only backups. Use it if you want additional backup management, configuration, history, or download features.

Open the secure configuration page

From a browser on your local network, visit https://EISY-IP:8768, replacing EISY-IP with your eisy's IP address.

The interface uses HTTPS. If your browser warns about a locally issued certificate, verify that you are connecting to your own eisy.

Create your administrator password

  1. On first access, enter and confirm a new administrator password.
  2. Use username admin and that password for subsequent logins.

Google Drive folder

The default Google Drive folder is eisy Backups. You can change the folder name in the HTML configuration interface if needed.

Important: If you have multiple eisy systems using the same Google account, configure a different folder for each installation. Otherwise, one system's retention policy could delete backups belonging to another.

Backup history and downloads

Use the HTML interface to review backup history, initiate backups, and download locally available backup archives.

USB Backup — Version 1.2.0

USB Backup provides an additional local copy of successful eisy backup archives alongside Google Drive.

Initial USB Drive Registration

  1. Connect a supported FAT-formatted USB drive to the eisy.
  2. Open the plugin's HTTPS configuration interface.
  3. Under USB Backup Settings, select the drive from the device list.
  4. Click Register USB Drive.
  5. Copy the SSH command displayed in the popup.
  6. Run that command in an SSH session connected to the eisy.
  7. Return to the web interface and click Complete Registration.
  8. Verify that the registered drive is recognized.
  9. Enable USB backups and save settings.

The setup command verifies the drive's FAT volume ID and installs a dedicated mount service. The service automatically mounts the registered drive at boot. The registration process does not format the USB drive.

USB backups are stored in:

/mnt/usbbackup/eisy-backups/

Creating USB Backups

When USB backups are enabled, each successful native eisy backup is copied to the registered USB drive.

  • Verifies the original ZIP archive.
  • Copies the archive to a temporary file.
  • Verifies the copied ZIP archive.
  • Renames the verified copy to its final filename.
  • Removes older archives according to USB retention settings.

USB retention is independent of Google Drive and local retention. USB copy failures are reported separately and do not change the successful primary backup result.

Viewing and Downloading USB Backups

The USB Backup Storage section displays saved backup filenames, file sizes, total capacity, available space, and individual Download controls. The drive must be registered and mounted for the listing to be available.

Safely Removing a USB Drive

  1. Click Safely Remove USB Drive.
  2. Confirm the operation.
  3. Wait for the interface to report successful removal.
  4. Disconnect the USB drive only after it has been unmounted.

USB backups are disabled when the drive is safely removed. Use Mount USB Drive to remount a registered drive.

Unregistering or Replacing a USB Drive

Safely unmount the drive first, then click Unregister USB Drive. Existing backup archives are not deleted.

To register a replacement drive:

  1. Safely remove and unregister the old drive.
  2. Connect the replacement drive.
  3. Refresh the USB device list.
  4. Register the replacement drive.
  5. Run the newly displayed SSH setup command.
  6. Return to the web interface and click Complete Registration.
  7. Enable USB backups.

USB Backup Status in IoX

  • USB Status: Not Configured, Ready, or Error.
  • USB Mounted: Yes or No.
  • USB Writable: Yes or No.
  • USB Free Space MB: Available USB storage.
  • Last USB Backup Result: Never Run, Success, Failed, or Disabled.

Check USB refreshes drive readiness; it does not create a backup. Drive status is checked periodically, and backup results are preserved in backup history.

USB Troubleshooting and Requirements

The current implementation supports FAT/MS-DOS USB partitions recognized as FreeBSD msdosfs. If the drive is not recognized, verify registration, drive identity, and mount status. Ensure sufficient free space is available.

USB storage is supplemental. Keep additional backup copies away from the eisy device.

Downloading and restoring a backup

For a successful backup ZIP still available on the eisy, select Download in Backup history. The plugin normally retains only the newest local ZIP; retrieve older archives from Google Drive.

To restore, download the desired ZIP and use the existing eisy-ui restore functionality. The plugin does not itself perform restores.

Troubleshooting

Backup creation fails

First verify Allow Unrestricted ISY Access is enabled for eisy Backup in PG3x. Then review the plugin status and logs.

Google Drive is not authenticated

Open the eisy Backup dashboard in PG3x and click Authenticate. Complete Google authorization and verify internet connectivity. Enable Google Drive Backup in IoX if cloud backups are desired.

No Download button for an older backup

The Download button appears only for successful archives still available locally. Retrieve older backups directly from Google Drive.

Cannot open the web interface

Check that the plugin is running, use https:// (not http://), and verify the eisy IP address and port 8768.

Security and privacy

Backups may contain sensitive system configuration. Protect any downloaded ZIP files. Google authorization tokens are stored locally, and uploads go directly to your authorized Google Drive account.

Read the Privacy Policy or visit the GitHub repository.

NAS Backup Access

Version 1.1.0 supports automated downloads of the latest successful local backup to a NAS or another computer.

  1. Open the backup plugin's HTTPS interface on port 8768.
  2. Sign in as administrator.
  3. Under NAS Backup Access, click Copy Token.
  4. Configure your NAS to download from: https://EISY-IP:8768/api/backup/latest
  5. Include the HTTP header: Authorization: Bearer YOUR_TOKEN

The endpoint downloads an existing backup. It does not create a new backup.

Use Regenerate Token to revoke the existing token and create a replacement. Update your NAS afterward.

Protect your API token and downloaded archives. Configure your NAS to trust the plugin's HTTPS certificate.

Multiple eisy Systems on One Google Drive Account

Multiple eisy systems can use the same Google Drive account. Configure a different Google Drive folder for each installation to keep their backups separate.

Example

  • Home eisy: eisy Backups - Home
  • Office eisy: eisy Backups - Office

Configuration

  1. Install eisy Backup on each system.
  2. Authorize each installation using the same Google account.
  3. Open the HTTPS configuration interface on each eisy.
  4. Enable Google Drive backups.
  5. Enter a unique name in the Google Drive folder field.
  6. Save the configuration and create a test backup.
  7. Verify that each backup appears in its designated Google Drive folder.

The default folder name is eisy Backups. Using separate folders keeps backups organized and allows each installation to manage its own retention settings independently.
