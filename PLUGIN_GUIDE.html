eisy Backup

Configuration and Google Drive setup guide

Important: Enable Unrestricted ISY Access

Before creating your first backup, enable “Allow Unrestricted ISY Access” for the eisy Backup plugin in PG3x. The plugin requires this permission to request native system backups from IoX.

  1. Open the PG3x plugin dashboard on your eisy.
  2. Select eisy Backup and open its configuration/settings.
  3. Enable Allow Unrestricted ISY Access.
  4. Save the setting and restart the plugin if prompted.

If this setting is disabled, backup creation may fail even when the web interface and Google Drive connection appear to work.

1 Open the secure configuration page

In a browser on your local network, visit https://EISY-IP:8768, replacing EISY-IP with the IP address of your eisy.

The configuration interface uses HTTPS. If your browser warns about a locally issued certificate, verify that you are connecting to your own eisy before proceeding.

2 Create your administrator password

  1. On first access, enter and confirm a new administrator password.
  2. Use username admin and that password for future logins.
  3. Keep the password secure. The interface also provides password change and recovery options.

3 Connect Google Drive

  1. In the Google Drive section, select Connect Google Drive.
  2. Open the Google authorization link shown on the page.
  3. Enter the displayed device verification code.
  4. Sign in to the Google account where you want backups stored and approve the requested permissions.
  5. Return to the plugin page and confirm that Google Drive reports connected.

The plugin requests the limited Google Drive drive.file permission, rather than unrestricted access to your entire Drive. Your Google account password is entered only on Google's authorization page.

4 Set the backup folder

  1. Under Backup settings, enter your preferred Google Drive folder name.
  2. Select Save settings.

The default folder name is eisy Backups.

5 Create and verify a backup

  1. Click Backup Now.
  2. Wait for the operation to finish.
  3. Check Backup history for the result.
  4. Confirm the archive is present in your Google Drive folder.
  5. Optionally check the last backup status in the IoX Admin Console.

Version 1.0.0 provides on-demand backups; it does not include automatic scheduling.

Downloading and restoring a backup

For a successful backup ZIP still available on the eisy, select Download in Backup history. The plugin normally retains only the newest local ZIP; retrieve older archives from Google Drive.

To restore, download the desired ZIP and use the existing eisy-ui restore functionality. The plugin does not itself perform restores.

Troubleshooting

Backup creation fails

First verify Allow Unrestricted ISY Access is enabled for eisy Backup in PG3x. Then review the plugin status and logs.

Google Drive is not connected

Return to the Google Drive section, reconnect, and complete the device authorization process. Verify internet connectivity.

No Download button for an older backup

The Download button appears only for successful archives still available locally. Retrieve older backups directly from Google Drive.

Cannot open the web interface

Check that the plugin is running, use https:// (not http://), and verify the eisy IP address and port 8768.

Security and privacy

Backups may contain sensitive system configuration. Protect any downloaded ZIP files. Google authorization tokens are stored locally, and uploads go directly to your authorized Google Drive account.

Read the Privacy Policy or visit the GitHub repository.

NAS Backup Access

Version 1.1.0 supports automated downloads of the latest successful local backup to a NAS or another computer.

  1. Open the backup plugin's HTTPS interface on port 8768.
  2. Sign in as administrator.
  3. Under NAS Backup Access, click Copy Token.
  4. Configure your NAS to download from: https://EISY-IP:8768/api/backup/latest
  5. Include the HTTP header: Authorization: Bearer YOUR_TOKEN

The endpoint downloads an existing backup. It does not create a new backup.

Use Regenerate Token to revoke the existing token and create a replacement. Update your NAS afterward.

Protect your API token and downloaded archives. Configure your NAS to trust the plugin's HTTPS certificate.
